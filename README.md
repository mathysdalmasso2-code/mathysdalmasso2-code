### 💻 Côté Tech & Code
Je bosse principalement avec :
* **Python / MicroPython** pour automatiser des trucs ou programmer des cartes.
* **C++** quand il s'agit de pousser un peu plus loin sur microcontrôleur (Arduino, Raspberry Pi Pico).
