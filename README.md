## 🚀 Projets & Réalisations

* **Projets scolaires STI2D SIN :**
  * *Cartographie environnementale :* Gestion de capteurs climatiques (DHT20) et affichage sur ruban LED NeoPixel via MicroPython sur Raspberry Pi Pico.
  * *Monitoring matériel :* Script Python et code C++ sur Arduino pour afficher en temps réel l'utilisation de la RAM sur un écran LCD RGB.
  * *Traitement de capteurs :* Acquisition de données colorimétriques via un capteur I2C (VEML6040) sur carte BitMaker.
* **Projets personnels & Passion :**
  * Expérimentations et automatisation de configurations logicielles.
  * Maintenance, optimisation et personnalisation de systèmes informatiques et matériels.
